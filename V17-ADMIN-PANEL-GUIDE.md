# YonoLootZone Full Admin Panel V17

This version adds an AdminLTE-style PHP administrator panel inspired by the uploaded reference project's structure.

Open:
- /admin/
- First-time setup: /cms/setup.php if no admin password exists.

Admin modules:
- Dashboard
- Games / Add Game
- Posts & Updates
- Promo Codes
- Categories
- Homepage
- Telegram
- Appearance
- SEO Center
- Notifications
- Media Library
- Backup / Restore
- System Settings

The panel uses the existing YonoLootZone server-side CMS JSON data and generates public game/post HTML pages.

Important:
- Existing static SEO pages are preserved.
- Keep a backup before replacing production files.
- This is a PHP hosting deployment; Hostinger PHP hosting is expected.
- The admin panel is noindex and protected by the CMS password.
