# V16 CMS — Game + Promo Post Upgrade

## New post options

When creating a post in `/cms/`, you can now:

- Select an existing game from **About Game**.
- Automatically add the selected game's name, image, and separate public game-page link.
- Add a dedicated **Promo Code** section.
- Enter promo code, reward/offer, minimum deposit, expiry, and terms/notes.

## Example

Select: `Teen Patti Gold Yono`

The published post automatically gets a game card linking to the game's existing page, such as:

`https://yonolootzone.com/games/teen-patti-gold/index.html`

## Daily promo workflow

1. CMS → Publish Post
2. Choose `Game Update` or `Promo Code Update`
3. Select the game in **About Game**
4. Tick **Add promo code box to this post**
5. Enter the current promo code and verified terms
6. Add your article and image
7. Preview/publish

The promo section includes a note telling readers to verify availability and eligibility in the game/app. Do not publish unverified or universal claims about account-specific offers.
